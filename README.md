# Sasirangan Banua

Situs web katalog kain dan busana **Sasirangan** khas Banjarmasin yang menampilkan
produk pengrajin lokal. Dibuat sebagai proyek **Praktikum Pemrograman Web 1**,
Program Studi Teknik Informatika, Universitas Islam Kalimantan Muhammad Arsyad
Al Banjari (UNISKA MAB).

**Demo langsung:** https://reivhell.github.io/web-2510010121/

## Fitur

- Halaman beranda dengan bagian hero, katalog produk, dan profil singkat.
- Katalog produk (6 kartu) yang tersusun rapi dengan CSS Grid.
- Tabel jadwal buka galeri.
- Halaman formulir pemesanan (`kontak.html`) dengan validasi bawaan HTML5
  (kolom wajib, pola nomor WhatsApp, jumlah, dan persetujuan).
- Tampilan responsif (ponsel, tablet, desktop) dengan pendekatan *mobile-first*
  dan media query.
- Navigasi dengan penanda fokus keyboard dan dukungan `prefers-reduced-motion`.

## Teknologi

HTML5, CSS3 (Flexbox, Grid, *custom properties*, media query), Git, dan GitHub Pages.

## Cara Menjalankan di Komputer

1. Salin (_clone_) repositori ini.
2. Buka foldernya di Visual Studio Code.
3. Klik kanan `index.html`, lalu pilih **Open with Live Server**.

> Halaman sebaiknya dibuka melalui server (Live Server atau GitHub Pages) agar
> tampil konsisten.
